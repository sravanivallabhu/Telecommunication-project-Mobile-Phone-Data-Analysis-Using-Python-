 **# Mobile Phone Data Analysis Using Python

## 📌 Project Overview

This project focuses on analyzing a mobile phone dataset using Python. The main objective is to explore mobile phone specifications, perform statistical analysis, and identify meaningful patterns in the data.

The project uses Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn for data manipulation, statistical calculations, and exploratory data analysis (EDA).

## 🎯 Objectives

- Understand mobile phone specifications and their features.
- Perform data preprocessing and manipulation.
- Create new features using existing columns.
- Apply logical conditions to filter the dataset.
- Calculate descriptive statistical measures.
- Analyze the ratio of standard deviation to mean.
- Sort numerical features based on their variation.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 📊 Key Analysis Performed

1. Loaded and explored the mobile phone dataset.
2. Created new features based on screen resolution.
3. Analyzed numerical features using descriptive statistics.
4. Calculated mean, median, quartiles, and standard deviation.
5. Applied multiple logical conditions to filter records.
6. Sorted the dataset based on mobile phone prices.
7. Calculated the coefficient of variation (standard deviation / mean) for numerical features.
8. Sorted the calculated ratios in descending order.
